## 🧠 About Me

I'm a Computer Science student at **FAST-NUCES Lahore** working across the full stack — Flutter and React on the front end, Firebase and T-SQL behind it. My focus is software that real businesses run on, not coursework that ships to a grade.

The clearest example is **Umme Hassan Clothing**: I'm lead developer on a live clothing storefront running on iOS, Android, and Web, now at 600+ organic users. I own the codebase, the admin tooling, and the growth side — Meta catalogue, Google SEO, and the ongoing site expansion.

Alongside that I've built operational tools people actually use — a tuition-center management system that replaced paper attendance and fee ledgers, and a multi-role freelance marketplace. I lean on AI-assisted workflows to move quickly, but the architecture decisions stay mine.
