## Projects

### Umme Hassan Clothing — production eCommerce platform
**Flutter · Firebase · Firestore · Bunny.net**

Lead developer on a live clothing storefront shipping to iOS, Android, and Web from a single Flutter codebase. Owned it end to end: requirements, architecture, deployment, and the growth work after launch.

- Real-time inventory and order sync via Firestore, so stock never oversells across three platforms
- Custom admin panel for inventory management and order fulfilment — the business runs the store without touching code
- Social authentication plus Firebase security rules; streamlined Cash-on-Delivery checkout tuned for the local market
- Media served through Bunny.net CDN to keep image-heavy catalogue pages fast on mobile data
- **600+ organic users** acquired through Meta catalogue integration and Google SEO

### Academify — tuition & academy management system
**Flutter · Firebase**

A management system for local educational centers that replaced manual attendance registers and fee ledgers.

- Class-wise records across multiple student batches with role-based owner/teacher access
- Single and batch fee-slip generation with PDF export — the feature that actually got it adopted
- Built against real workflows from the centers using it, not an imagined spec

### FastLance — freelance marketplace
**React · Vite · T-SQL**

A web marketplace with distinct client and freelancer roles and a full bidding flow.

- Relational schema designed for secure project tracking and transaction logs
- Modular component architecture with optimized state management
- Covered the full path from database design through UI

### FastGram — social network simulation
**C++ · Raylib**

An Instagram-like desktop application built from scratch as a semester project — no UI framework beyond Raylib.

- Profile management, posting, and a friends/pages system
- State-based GUI navigation and local file-based persistence
- A full OOP application where every abstraction was hand-rolled

### GML-Audit — laundering detection with graph neural networks
**Python · GNNs** · *university research project*

Coursework applying graph neural networks to detect laundering patterns in virtual-economy transaction data.

- Graph-based modeling over transaction networks
- Traversal algorithms for anomaly clustering and identifying circular laundering patterns
- Research stage — a framework for the problem, not a deployed system
